| Term | Definition |
| --- | --- |
| Issue | Lending a book copy to a member |
| Reserve | Holding a book for a member until available |
| Fine | Daily charge for late returns |
| Oversell | Issuing more copies than available |
| Member | Library user (role: user) |
| Librarian | Staff role with lending privileges |
| Admin | Staff role with management + audit privileges |
| Audit trail | Append-only log of admin setting changes |
| Challenge | Reading goal with streaks |
| Streak | Consecutive days meeting a reading goal |
| Wishlist | Saved books a member wants |
| Feed | Social posts stream |
| Realtime | Socket.IO push notifications |
| Recommender | Rule-based "for you" engine |
| AI companion | Keyword-intent reading assistant |
| Storage adapter | Service that owns the SQLAlchemy session |
| Fail-fast boot | Refusing to start with insecure defaults |
| Magic bytes | File signature check for uploads |
